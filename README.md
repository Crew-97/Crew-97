## 기술을 사용한 경험

- **배포·운영:** EC2, Docker Compose, Jenkins, Nginx로 서버와 자동 배포를 구성했습니다.
- **관찰·문제 대응:** Prometheus, Grafana, Loki로 메트릭·로그를 확인하고 운영 알림을 연결했습니다.
- **백엔드:** Python·FastAPI 기반 문서 검색 API를 구현했고 Java·Spring을 학습하고 프로젝트에 적용하고 있습니다.
- **화면·통합:** Vue 화면 구현과 지도 연동, 팀 작업의 기준 문서 작성·변경 통합을 경험했습니다.
